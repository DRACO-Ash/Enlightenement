Procedure · PROC-MNV

Manoeuvre detection and characterisation

Detect that an object has departed from its orbital state, establish whether the departure is real, characterise the burn by direction and magnitude, and assess whether the resulting geometry changes the threat picture.

Enter when any of these
·Residual plot shows a sustained departure from the zero line
·A provider reports a possible or verified manoeuvre
·An object of interest fails to appear where its state predicts
·A predictive surveillance check shows drift rate or longitude inconsistent with the last known state
·An established station-keeping pattern stops
Not this procedure when
·The headcount is greater than one — enter separation, breakup or UCT discovery first and treat manoeuvre as a supporting assessment
·The departure is explained by epoch age or an observation gap — there is no manoeuvre to characterise
·The object is in a launch or orbit-injection sequence, where planned burns are processed under launch

Verify the state before believing the departure. Check the epoch age of the element set the residuals are computed against, and the observation density either side of the departure.

Common error

Calling a manoeuvre off a single outlying observation rather than a sustained departure.

Why

A departure from a starved or stale fit is propagation error, not a burn. Skipping this step is the single most common cause of a wrong manoeuvre call.

Decision · MNV-D1 stop · think · then choose

Is the departure explained by data quality rather than by the object moving?

If

Epoch age exceeds the working limit, or observation density collapsed before the departure

Then

Treat as unassessable. Request updated states and observations covering the period. Do not report a manoeuvre.

If

State is current and observations are dense either side

Then

Proceed to characterisation.
